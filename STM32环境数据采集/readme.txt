/**
 ***************************************************************************************************
 * 项目简介
 * 项目名称：光照强度实时采集与显示系统
 * 工程名称：STM32环境数据采集 (EnvCollect)
 * 硬件平台：正点原子 精英版V2 (STM32F103ZET6, 512KB Flash / 64KB SRAM / 72MHz)
 * 显示设备：正点原子 3.5寸 TFTLCD (NT35310, 480x320, 16位8080并口 / FSMC)
 * 编译环境：Keil MDK5 + Arm Compiler 6 (armclang)
 * 工程文件：Projects\MDK-ARM\STM32环境数据采集.uvprojx
 * 当前版本：V1.0
 *
 ***************************************************************************************************
 * 项目目的
 * 1 掌握板载光敏电阻 LS1 与 STM32 内部 ADC3 的配合使用；
 * 2 掌握彩色 TFTLCD（MCU屏, FSMC 16位并口）的显示方法与"局部刷新"技巧；
 * 3 建立一套"非阻塞任务调度 + 传感器注册表 + 集中配置"的可扩展工程架构，
 *   为后续添加温湿度、燃气检测、4G/WiFi 上传等功能预留好位置。

 ***************************************************************************************************
 * 硬件资源及引脚分配
 * 1 光敏传感器（板载 LS1 光敏电阻）
     LIGHT_SENSOR   : PF8   （IO分配表标注为固定占用 N, 专供光敏, 不可挪作他用）
     ADC3           : 通道6, 即 ADC3_IN6, 12位精度, 采样时间 239.5 个ADC时钟周期
 * 2 正点原子 2.8/3.5/4.3/7/10寸 TFTLCD 模块（仅限MCU屏, 16位8080并口驱动）
     LCD 背光       : PB0
     触摸           : PB1(T_SCK) / PB2(T_MISO) / PF9(T_MOSI) / PF10(T_PEN) / PF11(T_CS)
                      本工程只做IO配置, 不做触摸交互（需要时移植 实验26）
     FSMC 数据/控制 : PD0/1/4/5/8/9/10/14/15, PE7~PE15, PG0, PG12
 * 3 LED灯
     DS0（RED）     : LED0 - PB5    心跳灯, 程序在跑就闪
     DS1（GREEN）   : LED1 - PE5    报警灯, 低电平点亮
 * 4 蜂鸣器（板载）
     BEEP           : PB8           报警时断续鸣叫, 高电平鸣叫（注意与LED相反）
 * 5 独立按键
     KEY0           : PE4           报警阈值 -5%
     KEY1           : PE3           报警阈值 +5%
     KEY_UP(WK_UP)  : PA0           把当前阈值保存到 24C02
 * 6 24C02 EEPROM（板载, 软件IIC）
     IIC_SCL        : PB6
     IIC_SDA        : PB7
 * 7 串口1 (PA9/PA10连接在板载USB转串口芯片CH340上面), 115200-8-N-1
 * 8 SWD 调试/下载口: PA13/PA14（本工程绝不占用）

 ***************************************************************************************************
 * 工程结构
   STM32环境数据采集\
     App\                       应用层（本项目新写, 扩展点都在这一层）
       app_config.h             全局配置：功能开关 / 时间参数 / 阈值 / 预留引脚
       app_sched.c  .h          时间片任务调度器（1ms心跳 + 软定时器任务表）
       app_sensor.c .h          通用传感器注册表（加传感器 = 加一行）
       app_light.c  .h          光照采集：ADC3采样 -> 滑动平均 -> IIR -> 标定 -> 分级
       app_display.c.h          显示：表驱动布局 + 局部刷新
       app_alarm.c  .h          报警：滞回判断 + LED/蜂鸣器 + 执行器扩展钩子
       app_console.c.h          串口：CSV 数据流 + 任务表打印
       app_key.c    .h          按键：调阈值 / 存 24C02
       app_io.c     .h          扩展槽：留给你加新功能的地方（默认关闭）
     Drivers\                   驱动层（原样复用正点原子官方代码, 未做魔改）
       SYSTEM\  sys / delay / usart
       BSP\     LED LCD ADC(adc+adc3) DMA LSENS BEEP KEY IIC 24CXX
                TOUCH\  已放入但未加入工程, 供以后做触摸交互用
       CMSIS\   Include / Device
     User\main.c                主程序, 只做初始化 + while(1){ app_sched_run(); }
     Projects\MDK-ARM\          Keil 工程
     Output\                    编译产物（EnvCollect.hex 可直接下载）
     readme.txt / 项目说明.md / 扩展开发模板.md / keilkill.bat

 ***************************************************************************************************
 * 实验现象
 * 1 上电后 LCD 显示:
     顶部  标题栏 "STM32 ENV DATA COLLECT" 与在线传感器个数;
     中部  光照卡片: 大字百分比 + 单位 + 等级文字 (V.DARK/DARK/NORMAL/BRIGHT/V.BRIGHT)
           + 彩色条形图（带红色报警阈值刻线）+ 原始ADC码值 + 滤波参数 + 采样次数;
     底部  状态栏: 运行时间 / 报警阈值 / 按键提示。
 * 2 数值随光照实时变化: 用手指遮住LS1, 数值降到 0~20; 用手电筒照射, 升到 80~100。
 * 3 LED0(PB5) 以约 2.5Hz 闪烁, 提示程序在运行。
 * 4 串口每 500ms 输出一行 CSV, 开机时打印配置信息和任务表（供以后接4G/WiFi上传）。
 * 5 光强超过报警阈值（默认70%）时 LED1 常亮 + 蜂鸣器断续鸣叫, 降低后自动解除。
 * 6 按 KEY0/KEY1 调整阈值, 按 KEY_UP 保存, 断电重启后阈值仍然记得。

 ***************************************************************************************************
 * 注意事项
 * 1 电脑端串口调试助手波特率必须是115200, 请使用XCOM/SSCOM串口调试助手, 其他串口助手可能
   控制DTR/RTS导致MCU复位/程序不运行。
 * 2 请用USB线连接在USB_UART, 找到USB转串口(CH340)后测试本工程。
 * 3 USART1的PA9/PA10必须通过跳线帽连接在RXD/TXD上（也就是 P3 要插上）, 否则没有串口输出。
 * 4 建议拔掉 P7 跳线帽（多功能接口 DAC/ADC/TPAD/RV1）: adc3_init() 内部会顺手把 PA1 也配成
   模拟输入, 拔掉 P7 可以避免 TPAD/DAC 往 PA1 灌电流。
 * 5 3.5寸屏背光吃 3.3V 轨约 120mA, 板子本体 30~65mA, 用 USB 供电即可（上限500mA）。
   如果要加 4G 模块（发射峰值可达 2A）, 请换 12V/3A 适配器并给4G独立供电。
 * 6 本工程使用 Arm Compiler 6 (AC6)。你的 MDK 是 5.43a, 里面没有安装 AC5,
   所以不要把它切回 AC5, 否则会报 "Arm Compiler 5 not found"。
 * 7 光敏电阻的阻值与光照不是线性关系, 本工程沿用官方换算公式（ADC码值/40, 再取反）,
   分辨力约 2.44%/级。需要更细的分辨力可以改 App\app_light.c 里的映射曲线。
 * 8 LCD 界面只能显示 ASCII, 不能显示中文。原因是官方 lcd.c 的字库（lcdfont.h）只有
   12/16/24/32号 ASCII 点阵, lcd_show_string() 的循环条件是 (*p <= '~' && *p >= ' '),
   中文字节（>0x7E）会让循环立刻退出。要显示中文需要移植 实验36 汉字显示实验 的字库方案。
 * 9 想加新功能: 先看 扩展开发模板.md, 再改 App\app_config.h / app_sensor.c / app_sched.c。
