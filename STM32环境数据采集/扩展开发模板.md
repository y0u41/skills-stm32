# 扩展开发模板 · 在这块板子上加新功能

> 配套文档：`项目说明.md`（架构与引脚） / `readme.txt`（现象与注意事项）
> 本文件回答一个问题：**"我想加个 XXX，该动哪几个文件？"**

工程里已经埋好了三条"扩展轨道"，按你的需求选一条走：

| 你想做的事 | 走哪条轨道 | 改动量 |
|---|---|---|
| 加一个**能被界面显示、进 CSV**的传感器 | 轨道 A：注册表 | 3 步 |
| 加一个**后台周期性任务**（不需要显示） | 轨道 B：任务表 | 2 步 |
| **先随便试一段代码**，不确定要不要留 | 轨道 C：扩展槽 | 1 步 |
| 超阈值时**驱动继电器/电磁阀/风扇** | 轨道 D：执行器钩子 | 1 处 |
| 只是**改参数**（周期、阈值、开关） | 轨道 E：配置文件 | 1 行 |

## 轨道 A：加一个能被界面和串口自动带上的传感器

**效果**：往注册表加一行之后，**屏幕上自动多出一张卡片**（含标题、大字数值、单位、条形图、
在线状态，卡片高度自动分档），**串口 CSV 自动多出一列**。显示模块一个字都不用改。

以加 **DHT11 温湿度**（板载 `U4` 座，PG11，直插免接线）为例。

### 第 1 步：把底层驱动放进 `Drivers/BSP/`

从官方 **实验29 DHT11** 里把 `dht11.c` / `dht11.h` 复制到 `Drivers\BSP\DHT11\`，
然后在 Keil 里 `右键 Drivers/BSP 组 → Add Existing Files` 加进去。

> 官方 `dht11.c` 用的是 PB/PC 口时钟宏吗？不是——它用的是 **PG11**（单总线座 U4），
> 而 `dht11.h` 里已经定义好了，直接抄过来就能用，不用改引脚。

### 第 2 步：在 `App/` 下新建 `app_dht11.c` / `app_dht11.h`

```c
/* app_dht11.h */
#ifndef __APP_DHT11_H
#define __APP_DHT11_H
#include "./SYSTEM/sys/sys.h"

uint8_t app_dht11_sensor_init(void);          /* 返回 0 = 成功 */
uint8_t app_dht11_sensor_poll(int32_t *out);  /* 结果写到 *out, 返回 0 = 成功 */

/* 温湿度是两个物理量, 用一个全局变量在两个 poll 里各取一份 */
uint8_t app_dht11_get_temp(void);
uint8_t app_dht11_get_humi(void);

#endif
```

```c
/* app_dht11.c */
#include <stddef.h>
#include "app_config.h"
#include "app_dht11.h"
#include "./BSP/DHT11/dht11.h"

static uint8_t s_temp = 0;
static uint8_t s_humi = 0;

uint8_t app_dht11_sensor_init(void)
{
    return dht11_init();          /* 官方 dht11_init 返回 0 表示成功 */
}

uint8_t app_dht11_sensor_poll(int32_t *out)
{
    uint8_t t = 0, h = 0;

    if (dht11_read_data(&t, &h) != 0)   /* 读失败(校验和不对/没插) */
    {
        return 1;                        /* 返回非 0, 注册表会把该传感器标记为掉线 */
    }

    s_temp = t;
    s_humi = h;

    if (out != NULL)
    {
        *out = (int32_t)t;               /* 这一次 poll 报"温度" */
    }

    return 0;
}

uint8_t app_dht11_get_temp(void) { return s_temp; }
uint8_t app_dht11_get_humi(void) { return s_humi; }
```

> ⚠ `dht11_read_data()` 内部有毫秒级延时，**一次约 5ms**。
> 放在 500ms 周期的任务里没问题（占 1% CPU），**千万不要**放进 20ms 的按键任务里。

### 第 3 步：到 `App/app_sensor.c` 的 `g_sensors[]` 里加两行

打开 `app_config.h` 把开关打开：

```c
#define APP_USE_DHT11    1
```

然后在 `App/app_sensor.c` 的注册表里（注释示例的位置）加：

```c
#if APP_USE_DHT11
    { "TEMP", "TEMPERATURE", "C",
      app_dht11_sensor_init, app_dht11_poll_temp,
      -20, 60, 0, 0, 0, 1,  NULL, NULL },
    { "HUMI", "HUMIDITY", "%",
      app_dht11_sensor_init, app_dht11_poll_humi,
      0, 100, 0, 0, 0, 1,  NULL, NULL },
#endif
```

并在 `app_sensor.c` 顶部 `#include "app_dht11.h"`。

**完事。** 编译后屏幕上会自动出现 TEMPERATURE 和 HUMIDITY 两张卡片，
串口 CSV 自动变成 `# tick_ms,alarm,th,LIGHT,TEMP,HUMI`。

### 注册表字段顺序（照抄这个，别漏）

```
英文短名, 界面标签, 单位,
init函数, poll函数,
量程下限, 量程上限,
当前值(填0), 采集次数(填0), 在线标志(填0), 启用标志(填1),
等级文字钩子(NULL=不显示), 颜色钩子(NULL=黑色)
```

### 可选：让数值带颜色和等级文字

参照 `app_light.c` 里的 `app_light_level_text()` / `app_light_level_color()`，
写两个同签名的函数填进注册表的最后两格即可。

## 轨道 B：加一个后台周期任务

**效果**：到点自动执行，不需要显示，不阻塞别的功能。

### 第 1 步：写任务函数

```c
/* 放在 App/app_xxx.c 里, 头文件里声明 void app_xxx_task(void); */
void app_xxx_task(void)
{
    /* ★ 铁律: 这里绝对不能有长延时 (不要 delay_ms(500) 这种),
     *   否则整个调度器都被你卡住, 显示和采集全部变慢。
     *   需要"等一会儿"就用全局 1ms 计数自己判断:
     *       static uint32_t last = 0;
     *       if (app_sched_get_tick() - last < 100) return;
     *       last = app_sched_get_tick();
     */
}
```

### 第 2 步：到 `App/app_sched.c` 的 `g_tasks[]` 里加一行

```c
{ "xxx", 100, 0, app_xxx_task, 1, 0 },
/*  ^名   ^周期ms ^填0 ^任务函数   ^1=启用 ^填0(运行次数由程序统计) */
/* ★★★ 新任务加在这里 ★★★ */
```

`enable` 写 `0` 就是先不跑，方便你分阶段调试。
开机 5 秒后串口会打印一次任务表，可以确认任务确实在跑。

## 轨道 D：超阈值时驱动继电器 / 电磁阀 / 风扇

只改 **一个函数**：`App/app_alarm.c` 里的 `app_alarm_actuator()`。

```c
static void app_alarm_actuator(uint8_t on)
{
    /* 只在报警状态"发生变化"的那一刻被调用一次, 不是每周期都调 */
    sys_gpio_set(GPIOD, SYS_GPIO_PIN11, SYS_GPIO_MODE_OUT,
                 SYS_GPIO_OTYPE_PP, SYS_GPIO_SPEED_LOW, SYS_GPIO_PUPD_PD);
    sys_gpio_pin_set(GPIOD, SYS_GPIO_PIN11, on ? 1 : 0);
}
```

### ★★★ 强电部分的安全红线（务必逐条照做）

1. **继电器/电磁阀绝对不能直接挂在 GPIO 上。** 必须
   `GPIO → 限流电阻 → 三极管(或 MOSFET) → 继电器线圈`，
   线圈两端**反向并一个续流二极管**（1N4148 / 1N4007）。
2. **不要从开发板的 5V / 3.3V 排针给继电器或电磁阀取电。** 请外接电源，**只共地**。
   板子排针各限 1000mA（USB 供电时只有 500mA），电磁阀吸合瞬间的浪涌会把 MCU 拉复位。
3. 有市电的一侧建议加**光耦隔离**（PC817 等），并注意强电爬电间距。
4. **燃气电磁阀是脉冲式的**（吸合 50~200ms 后靠永磁保持），吸合电流可达 1.7A，
   你的 12V/1.0A 适配器带不动，**必须换 12V/3A**，且用大电容 + 独立供电。
5. 上电前用万用表量一遍电源对地电阻，防短路。

> 完整物料与电源核算见 `D:\正点原子\元器件选型报告_STM32F103ZET6环境监测与燃气报警.md`。

## 常见扩展的具体建议

| 想加的功能 | 硬件接哪 | 软件走哪条轨道 | 备注 |
|---|---|---|---|
| DHT11 温湿度 | 板载 `U4` 座（PG11），**直插** | A | 官方实验29 |
| DS18B20 温度 | 同上 | A | 官方实验28，与 DHT11 二选一 |
| MQ-2 燃气 | PC1 (ADC12_IN11) | A | ⚠ **必须先 10k/20k 分压**，5V 会打坏引脚 |
| MQ-135 空气质量 | PC2 (ADC12_IN12) | A | 同上 |
| 光照曲线记录 | 已有 PF8 | B + TF 卡 | 移植实验35 FATFS，或存 W25Q128 |
| 4G 短信报警 | 板载 `ATK-MODULE` 座（PB10/PB11） | B | `usart3_init(72,115200)`，CSV 行直接当载荷 |
| WiFi 上传 | 同上 | B | 同上 |
| 继电器切断燃气阀 | PD11 + 三极管 | **D** | 看轨道 D 的安全红线 |
| 风扇调速 / 补光灯调光 | PC6 (TIM8_CH1) | B | `atim_timx_pwm_chy_init(1000-1, 72-1)` → 1kHz |
| 触摸屏交互 | 屏自带 | 新增 | 移植实验26，把 `Drivers/BSP/TOUCH/` 加进工程 |
| 汉字显示 | 屏 | 新增 | 需要移植实验36 的字库方案，见 `项目说明.md` §4.4 |
| 加时间戳 | PC14/PC15 晶振 + VBAT | B | 移植实验15 RTC |
| 上位机曲线 | 串口 CSV | 不用改 | 直接用 Python/Excel 读 `Output` 里的 CSV 流 |
| 掉电保存更多参数 | 板载 24C02 | E | 地址 0x00~0xFE 可用，**255 被 `at24cxx_check()` 占了** |
